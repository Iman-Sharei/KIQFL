KIQFL is an open research codebase for hybrid quantum–classical federated learning: central-server aggregation, Hybrid CNN–QNN clients, and fidelity-guided weights under simulated NISQ noise.

Quick start

From the project root (with your virtualenv activated):

Install 
pip install -r requirements.txt
Web UI 
python -m webapp
Quick experiment 
python -m core experiments --quick --suite main

Then open http://127.0.0.1:5000. Full CLI help: python -m core --help
