About the method

How KIQFL combines hybrid CNN–QNN clients, central-server aggregation, and fidelity-guided weights in a classical state-vector simulator.

{% endblock %} {% block content %}

Federated learning lets many devices improve a shared model without pooling raw data. In this project the shared model always lives on a central server: each round the server broadcasts parameters \(\omega_{\mathrm{global}}\), clients train on private data \(D_n\), and the server aggregates the returned parameter updates.

KIQFL (KAN-Enhanced Indirect Quantum Federated Learning) keeps that classical FL skeleton and adds a quantum-inspired weighting step. Each Hybrid CNN–QNN client also exposes a circuit statevector \(\lvert\psi_n\rangle\). Those states may be mixed on a ring by a discrete-time quantum walk (DTQW); a Kolmogorov–Arnold network (KAN) sets a mixing strength \(\alpha\) between each local state and its walked neighbor state. Aggregation weights then come from pure-state fidelity to the previous global circuit state. Parameter exchange itself remains server-centric—it is not a peer-to-peer parameter protocol.

System architecture

\(N\) clients train for \(K\) local epochs, then send updates to the server. The server builds a new \(\omega_{\mathrm{global}}\) with fidelity-guided aggregation (KIQFL) or with baseline rules (FedAvg / FQNGD) and broadcasts it for the next round.

Hybrid CNN–QNN client model

A classical CNN extracts a feature vector, which is padded or truncated to length \(2^{n}\) and \(\ell_2\)-normalized for amplitude encoding. A layered parameterized circuit (typically \(R_y\) rotations and nearest-neighbor CNOTs, with optional simulated NISQ noise and optional QAOA layers) evolves the state. Computational-basis probabilities feed a classical linear head. Training uses state-vector simulation with autograd through the circuit—not a claim of real-QPU wall-clock advantage.

Amplitude encoding of a real feature vector \(x\):

$$\lvert\psi_{\mathrm{enc}}(x)\rangle = \frac{1}{\lVert x\rVert}\sum_{i=0}^{2^{n}-1} x_i\lvert i\rangle$$

Parameterized circuit (layer product; \(L\) variational layers):

$$U(\theta)=\prod_{\ell=1}^{L} U_\ell(\theta_\ell),\qquad \lvert\psi_{\mathrm{out}}\rangle = U(\theta)\lvert\psi_{\mathrm{enc}}\rangle$$

Fidelity-guided aggregation

After local training, each participating client uploads model parameters \(\omega_n\) and a circuit state \(\lvert\psi_n\rangle\) (optionally after DTQW+KAN mixing). KIQFL scores clients with pure-state fidelity against the previous global circuit state \(\lvert\psi_{\mathrm{global}}\rangle\):

$$F\!\big(\lvert\psi_n\rangle,\lvert\psi_{\mathrm{global}}\rangle\big) =\big\lvert\langle\psi_n\mid\psi_{\mathrm{global}}\rangle\big\rvert^{2}$$

Non-negative weights are normalized and applied to the classical parameter tensors (not to a coherent sum of quantum states):

$$w_n=\frac{F_n}{\sum_{j} F_j},\qquad \omega_{\mathrm{global}}\leftarrow\sum_{n} w_n\,\omega_n$$

One KIQFL round

Input: global rounds \(R\), local epochs \(K\), clients \(N\), learning rate \(\eta\)

[1] For each global round \(r = 1 \ldots R\):
Server broadcasts \(\omega_{\mathrm{global}}^{(r)}\)
Selected clients train locally for \(K\) epochs on the Hybrid CNN–QNN
Clients upload parameters \(\omega_n\) and circuit states \(\lvert\psi_n\rangle\)
Server mixes guidance states with DTQW on a ring; KAN sets \(\alpha\) for local–walked blending
Server aggregates parameters with fidelity weights vs \(\lvert\psi_{\mathrm{global}}^{(r)}\rangle\) (previous round)
Server extracts the next global circuit state from the updated global model

Output: final global model \(\omega^\star = \omega_{\mathrm{global}}^{(R)}\)

Scope — what we do not claim

  • We do not remove the central server or run fully peer-to-peer parameter exchange.
  • We do not claim wall-clock speedup on real QPUs; this codebase uses classical state-vector simulation.
  • Privacy still needs DP (optional Opacus) when required—the uncertainty principle alone is not a privacy proof.
